机组排班的目的是为各航班指派飞行所需的各岗位人员，同时结合机组人员的培训、休假等占位任务，生成特定时间段的日程安排。由于航班计划的变动，人员培训、值班、休假等占位任务的调整，机组排班通常在实际运行的前一周完成，属于航空公司的短期计划问题。

排班任务：参赛选手需要根据提供的机长数据，结合航班信息、占位任务及大巴置位信息等，在满足给定排班规则的前提下，制定指定日期内（2025年5月29日至6月4日）各机长的个人排班计划。提交任务范例包含"rosterResult.csv"文件，最后提交文件为csv格式，表格抬头已给出，选手须给出2025年5月29日至6月4日内**各机长的个人排班计划**。

评价指标：（1）选手需考虑机长资质、已有占位任务、基础规则限制等前提，[为各机长设计指定时段内的个人排班计划]{.mark}。（2）针对选手给出的排班方案，根据以下评价指标计分：

1.  [值勤日日均飞时]{.mark}：总飞行小时/总值勤日历日数量（当值勤日跨零点时，记为两个日历日），得分为值勤日日均飞时\*100；

2.  [未覆盖航班数量]{.mark}：计划航班未安排机长的数量，每个航班扣5分；

3.  [外站过夜天数]{.mark}：当过夜站点与所属基地不一致时，记为外站过夜。例如，假设所属基地为A，过夜天数计算规则如下：

7月1日到达B，7月2日于B起飞，记为外站过夜一天；

7月1日到达B，7月3日于B起飞，记为外站过夜两天。

统计排班方案中总过夜天数，每天外站过夜扣0.5分；

4.  [置位次数]{.mark}：统计排班方案中飞行置位和地面置位总数，每个置位扣0.5分。

5.  [违规次数]{.mark}：统计排班方案中发生违规的次数，违规指违背"名词释义与排班规则.docx"中的排班规则，每次违规扣10分。
